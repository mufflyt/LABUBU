The confounding I flagged last month has gotten more pronounced

If you just tally the calls, single mothers still look like they get scheduled far more often than the other callers — 67%, versus 44% for straight couples and 40% for lesbian couples. Please don't let that number into the paper. It is an artifact of which practices we called, and the gap is now wider than it was in July:

  • We've made a single-mother call at only 42 of 104 practices.
  • Those 42 practices are the easy-to-schedule ones. Their straight and lesbian calls get a yes 68% of the time.
  • The 62 practices we've never called for a single mother say yes to anyone only 17% of the time.

So the single-mother group is built almost entirely from friendly offices, while the other two groups mix friendly offices with all those 17% offices. The comparison is rigged by office selection, not by scenario.

Looking within one practice at a time — for offices called as more than one scenario, did the single-mother call get answered differently? — the advantage vanishes and slightly reverses. Single mothers do 6 points worse than the very same offices' straight callers and 3 points worse than their lesbian callers.

Bottom line, unchanged from July: the 67% is real arithmetic but a misleading comparison. The honest read is that practices largely treat all three callers the same, with no single-mother advantage.

The scenario comparison is still underpowered

The within-practice test only draws information from practices that answered differently to two callers. Most treat everyone alike, so only 11 to 13 practices per comparison actually carry signal — barely changed from the 9–11 in July, despite the extra calls. At that size we can only detect a very large effect (roughly a 4–6× odds difference). None of the three comparisons is close to significant (p = 0.58, 0.77, 1.00).

Adding calls has moved this number very little, which tells us the power problem is structural, not a matter of a few more calls. We should report these comparisons as exploratory / hypothesis-generating with an explicit power floor — not as null results.

What I'd suggest

  1. Lead the paper with the well-powered descriptive findings — service mix, overall access, concordance — rather than the scenario contrast.
  2. Present the scenario comparison as exploratory, using the within-practice matched analysis with an explicit power-floor statement.
  3. Drop the unmatched 67% entirely. It's confounded and a reviewer will flag it.
  4. If you have appetite for more calls, the 62 practices missing a single-mother call are the highest-value target — that's what de-confounds the comparison. Priority lists are in the project folder. But the descriptive paper doesn't need them.
